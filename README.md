# Bible Match

A Bible word game for church presentation and play, as a single self-contained HTML file.

Tap a word bubble and it flies up into its scripture page. Tap the book in the upper left corner to choose any of the 66 books of the Bible, or shuffle all books. Hints are free and unlimited, and follow the selected book in order.

Play: open `index.html` in a browser, or play the hosted GitHub Pages site.

Scripture: New International Reader's Version (NIrV), used within Biblica's quotation terms. See the credit strip in the game file for the full notice.
